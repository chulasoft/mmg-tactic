# Magic Maidens — Design Hub

โฟลเดอร์นี้เป็น source of truth สำหรับการออกแบบเนื้อเรื่องและระบบเกม
โดยแยกเนื้อหาที่เป็น canon ออกจากรายละเอียดการเล่น เพื่อให้สามารถแก้ไขแต่ละส่วน
ได้โดยไม่ทำให้ Story กับ Gameplay ปะปนกัน

## เอกสารหลัก

1. [`STORY_BOOK.md`](STORY_BOOK.md) — แก่นเรื่อง ตัวเอก กฎของความทรงจำ
   โครงสร้าง Act และบทเล่าเรื่องที่อนุมัติแล้ว
2. [`GAMEPLAY_BOOK.md`](GAMEPLAY_BOOK.md) — โครงสร้าง Scenario, Objective,
   Tutorial และเหตุการณ์ที่เกิดบนกระดาน
3. [`WORK_INSTRUCTIONS.md`](WORK_INSTRUCTIONS.md) — วิธีอัปเดตเอกสาร สถานะงาน
   decision log และรายการหัวข้อที่จะออกแบบใหม่ต่อ

## สถานะปัจจุบัน

- **Story Core:** วางแกนเบื้องต้นแล้ว
- **Protagonist Core:** วางแกนเบื้องต้นแล้ว
- **Act I:** ยังไม่กำหนดจำนวน Chapter สุดท้ายทั้งเกม แต่ล็อกทิศทาง Act I
  ให้เป็น Tutorial Arc และจบด้วยไคลแมกซ์ก่อนเข้าสู่ Act II
- **Prologue — The Table:** ร่างรายละเอียดรอบแรกแล้ว
- **Chapter 1 — The First Impact:** ร่าง Story และ Gameplay รอบแรกแล้ว
- **Chapter 2 เป็นต้นไป:** รอออกแบบร่วมกัน

> เอกสารชุดนี้เป็นแผนสำหรับเกม ยังไม่ถือว่า implementation ปัจจุบันในเกม
> ถูกเปลี่ยนตามเอกสารแล้ว จนกว่าจะมีการแก้ source code และอัปเดตสถานะอย่างชัดเจน
