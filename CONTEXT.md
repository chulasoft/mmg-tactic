## 1. What this project is

**Magic Maidens Tactic** is a tactical, turn-based, story-driven RPG that runs
entirely in the browser. Eight heroes, a grid battlefield, ability cards, and a
novel-style typewriter narrator. Original IP by **Soft** (solo creator).

- **One playable screen tree**, no accounts, no server. Open `index.html` → it runs.
- **Single-file React app.** All game logic lives in one `.jsx` file and is
  compiled to one `app.js` bundle. React 18 is loaded as a UMD global from a CDN
  — there is **no bundler, no `node_modules` at runtime**.
- Deploys as static files to GitHub Pages / Netlify / Vercel with **no build
  command**. The same source also runs inside the **Claude artifact viewer**.

If you only remember one sentence: *edit `src/magic-maidens-tactic.jsx`, rebuild
`app.js`, never hand-edit the bundle.*

## 3. Hard rules — do not break these

These are load-bearing. Several have already crashed the app once. Violating them
is the fastest way to ship a broken build.

1. **`src/magic-maidens-tactic.jsx` is the source of truth.** `app.js` is
   generated by `src/build.js`. **Never hand-edit `app.js`.**
2. **One file, default export `App`.** No new source files for game logic, no
   external CSS files — styles live in the `CSS` string constant.
3. **All React hooks at the top of every component, before any conditional
   `return`.** Hooks inside `if` blocks crashed the app with React error #310.
   Never repeat.
4. **No raw newlines inside single-quoted JS strings.** Story text uses `\n`
   escapes, `—` for em-dash, `’` for curly quotes. A raw newline
   crashed the app with "Invalid or unexpected token."
5. **No `localStorage` / `sessionStorage`.** They are blocked in the artifact
   sandbox. Persistence = file download / upload only.
6. **Every `<img>` needs an `onError` fallback** (hide or emoji). Portraits use
   crop `object-fit:cover; object-position:20% 10%` — keep it everywhere.
7. **The design language is locked.** Palette (one accent per semantic role),
   fonts (Fraunces + Outfit), radius scale, matte-dark-plus-gold tone. Do not
   introduce new accent colors, glassmorphism, parallax, or purple glows.
8. **Do not rewrite from scratch.** Extend and refactor incrementally.

Full, annotated rules with rationale: [`docs/SKILL.md`](docs/SKILL.md) and
[`docs/STYLE_GUIDE.md`](docs/STYLE_GUIDE.md).

## 4. How to verify your work

After **any** change to the game:

```bash
# 1. Rebuild the bundle from source
npm install --no-save @babel/core @babel/preset-react @babel/preset-env
node src/build.js          # must print "✅ app.js built — NNNkb", no errors

# 2. Serve and open (file:// blocks module loading in some browsers)
python3 -m http.server 8000
# open http://localhost:8000 — zero console errors, boot screen clears,
# Title → New Campaign → narrator → party select → battle must all work
```

Definition of done for a change: **`node src/build.js` succeeds, the site loads
with zero console errors, and the manual path above still works.** If you added
new state, wire it into the Admin panel so it can be inspected/jumped to.
